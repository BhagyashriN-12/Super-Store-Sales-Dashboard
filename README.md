*Superstore Sales Dashboard*

Description
This project is a Sales Dashboard created using Power BI to understand sales data in an easy and visual way. It helps analyze sales, profit, products, customers, and sales trends using different charts, graphs, and filters.

Tech Stack
The key technologies used to build the dashboard are:
📊 Power BI Desktop – Main tool used for data visualization and dashboard creation.
🔄 Power Query – Used for cleaning, transforming, and preparing the sales data.
🧮 DAX (Data Analysis Expressions) – Used to create calculated measures and KPIs for sales and profit analysis.
🗂️ Data Modeling – Used to create relationships between tables and organize the data for analysis.
📗 Microsoft Excel – Used as the source format for the sales dataset.

Features
- Interactive sales dashboard with KPIs and visualizations
- Analysis of total sales, profit, and orders
- Monthly sales trend analysis
- Product-wise sales and profit analysis
- Customer-wise sales analysis
- Region-wise sales performance
- Interactive slicers and filters for exploring the data
- Easy-to-understand charts and graphs for identifying sales trends and patterns
- Clean and simple dashboard layout for better data presentation
